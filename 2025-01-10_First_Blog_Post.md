A particular topic that interests me in cognition & computation is modeling human cognition using computational models. This interests me because in PHIL306 (Mathematical Logic and Model Theory), we discussed how models are used to represent theories. Theories, refer to a set of axioms (logical sentences) and a model for that theory is a set of elements and operators that follow those axioms.

For example, Peano Arithmatic is a theory which has all the necessary axioms for basic arithmetic (adding, multiplication, and exponentiation) and a model for this theory is the Natural Numbers. The natural numbers include elements {0,1,2,...} and operators {+,*,^} which are all present in Peano Arithmatic. 

Additionally, as a computer science major and learning about advancements in AI attempting to mimic advanced human functionality such as reasoning, problem solving, etc. Leaning about different ML learning type classifications such as supervised learning, unsupervised learning, deep learning etc. One model that many people use is neural networks which in a way mimics the neural network of a human brain.
